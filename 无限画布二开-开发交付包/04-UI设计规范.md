# 04 · UI 设计规范

> 设计稿在 `design/png/`（截图）和 `design/html/`（可以直接在浏览器打开的静态 HTML）。HTML 里的结构、文案、尺寸、颜色都可以直接参考。
> 设计稿中的数据（禾野茶饮、林舟、各种点数）都是示意，实际要接接口。`[品牌名]`、`[¥ 价格]` 是占位，分别对应运行期配置 `BRAND_NAME` 和 `credit_packages.price_cents`。

## 1. 设计原则

1. **延续原画布风格**：原项目在 `web/src/lib/canvas-theme.ts` 定义了一套暖石色板，并且 `AGENTS.md` 里有"画布 UI 规范"（扁平、低视觉重量、按钮不加灰色底）。新页面沿用这套视觉，让用户感觉是同一个产品。
2. **点数始终可见、扣费之前可预期**：凡是会扣点的按钮，文案里都带上点数，例如"生成 · 16 点"、"运行全部 · 预计 48 点"。
3. **品牌是默认开启的**：生成时自动套用当前品牌，并且明确告诉用户注入了什么（品牌页右侧预览、节点面板里的 ✓ 清单）。
4. **文案用中文**（AGENTS.md 的要求）。新增文案都加到 `i18n/locales/zh-CN.ts` 和 `en-US.ts`。

## 2. 设计 Token

### 2.1 颜色（浅色主题）

| Token | 值 | 用途 | 对应原项目 |
|---|---|---|---|

| `bg.sidebar` | `#f0eee8` | 左侧导航底色 | 新增 |
| `bg.card` | `#fbfaf7` | 卡片、浮层 | `node.panel` |
| `bg.input` | `#ffffff` | 输入框、下拉框 | — |
| `bg.subtle` | `#eeebe4` | 标签 chip、参数 pill | 新增 |

| `border` | `#e3dfd6` | 卡片描边、分割线 | 接近 `node.stroke` |
| `border.strong` | `#d6d3ca` | 次按钮描边 | `node.stroke` |
| `text.primary` | `#1c1917` | 正文、主按钮底色 | `node.activeStroke` |
| `text.secondary` | `#57534e` | 次要文字、图标 | `node.label` |
| `text.muted` | `#6b655d` | 说明文字（在 `bg.app` 上对比度 ≥ 4.5:1） | 新增，比 `node.muted` 略深，满足对比度要求 |
| `link` | `#2a49c9` | 链接、进行中状态、`@` 引用 chip 的文字 | 新增 |

| `success` | `#2f6b3a` | 已完成、已同步 | 新增 |
| `warning` | `#b45309` | 接近上限（≥ 90%）的进度条和图形。在浅底上的对比度约 4.5:1，**用作文字时**改用 `#9a4a07` | 新增 |
| `danger` | `#9a3412` | 额度不足、失败 | 新增 |
| `chart.image` / `chart.video` | `#1c1917` / `#c08a3e` | 用量柱状图 | 新增 |

深色主题：沿用 `canvasThemes.dark` 已有的值；新增的 token 按相同的明度关系推导，并加到 `lib/app-theme.ts` 中。**MVP 只要求浅色主题完整**，深色主题保证不出现白底刺眼的块即可。

实现方式：把上面的 token 写成 CSS 变量，放进 `styles/globals.css` 的 `:root` 和 `.dark`；同时配置 antd 的 `ConfigProvider` token（`colorPrimary: #1c1917`、`colorBgContainer: #fbfaf7`、`colorBorder: #e3dfd6`、`borderRadius: 10`），统一在 `lib/app-theme.ts` 里改。业务组件里**不要**写 `dark ? … : …` 这种分支。

### 2.2 字体

- 字体栈：`Inter, "Noto Sans SC", system-ui, sans-serif`。品牌 Logo 示意里用到的 `Noto Serif SC` 只是品牌自己的素材，不是产品字体。
- 字号：页面标题 24–26 / 700；区块标题 15–18 / 700；正文 13–14 / 400–500；说明文字 12；数字统计 28 / 700，加 `font-variant-numeric: tabular-nums`。

### 2.3 间距、圆角、尺寸

- 页面内边距 28–32px；卡片内边距 16–22px；卡片之间的间距 14–20px。
- 圆角：卡片 12px；按钮和输入框 8–10px；chip 5–6px；头像为圆形。
- 按钮高度：主要按钮 38–42px，画布内的按钮 32px，图标按钮 32×32。触控目标至少 44px（移动端）。
- 左侧导航宽 232px，导航项高 40px；画布左面板约 248px，右面板约 288px。

### 2.4 图标

使用 `lucide-react`，描边 1.8，尺寸 16–18。设计稿里的图标都可以在 lucide 里找到对应的：Home、LayoutGrid、Workflow、Gem、Image、FileText、Users、CreditCard、Settings、Sparkles、Share、Coins 等。

## 3. 全局布局（`layouts/workspace-layout.tsx`）

```
┌──────────┬──────────────────────────────────────────────┐
│ Logo     │ 顶栏：搜索（⌘K） · 从模板创建 · 新建画布 · 头像 │
│ 工作区切换 ├──────────────────────────────────────────────┤
│ 导航…     │                                              │
│ ──────    │ 页面内容（max-width 不限，内容自适应）           │
│ 团队/计费  │                                              │
│ 点数卡片   │                                              │
└──────────┴──────────────────────────────────────────────┘
```

- 导航项：首页 `/`、我的画布 `/canvas`、模板中心 `/templates`、品牌资产 `/brand`、素材库 `/assets`、提示词库 `/prompts`。分隔线之后是团队成员 `/team`、用量与计费 `/billing`、设置 `/config`。原有的生图工作台 `/image` 和视频工作台 `/video` 放进"更多"折叠组。
- 工作区切换：用 antd `Dropdown` 列出工作区，底部有"创建团队工作区"。
- 底部点数卡片：显示剩余点数和套餐上限、进度条、"充值点数 →"。余额低于 10% 时进度条改用 `warning` 色。
- Logo 下方的副标题固定显示"基于 infinite-canvas"（开源署名，不要删）。
- 宽度小于 768px 时，侧栏收成抽屉，原项目已有 `mobile-nav-drawer.tsx` 可以复用。
- **画布编辑页 `/canvas/:id` 不使用这个布局**，保持原来的全屏画布。

## 4. 各页面说明

### 01 工作台首页（`/`，登录后）· `design/png/01-工作台首页.png`

- 左侧主区域：
  - "从一个行业工作流开始"：4 张模板卡片，取 `GET /templates?scope=all` 的前 4 条，按 use_count 排序。卡片内容：节点流程缩略（三个小标签，来自 `previewNodes`）、名称、描述、分类 chip、"约 N 点 / 次"。点击跳 `/templates?id=…`。
  - "最近画布"：读取本地的 `useCanvasStore().projects`，按 updatedAt 倒序取 6 个。筛选 tab 有"全部 / 我创建的 / 团队共享"，后两个在第 2 期云端画布上线前先隐藏。缩略图优先用项目里第一张图片节点的预览图，没有就显示色块占位。
- 右侧：
  - 当前品牌套件卡片：Logo、名称、SKU 数、色板、"生成时自动注入：…"摘要。没有品牌时显示空状态"创建品牌套件，让生成自动符合品牌规范"，附"新建品牌"按钮。
  - 生成任务：`GET /billing/jobs` 的最近 4 条，每 5 秒轮询一次，只在页面可见时轮询。状态文案：生成中（`link` 色）、排队中、已完成（`success` 色）、额度不足或失败（`danger` 色）。

在原画布上**只做加法**：

   - 原有的"画布助手"按钮保持不变。
   - "已同步到云端"这个状态在第 2 期之前改成显示"已保存在本机"。
2. **左面板**新增"品牌""模板"两个 tab，放在"画布"和"素材"之间：
   - 品牌 tab：SKU 九宫格（可以拖进画布，拖入后生成图片节点）；风格参考图（显示"生成时自动附带"）；色彩与 Logo；提示词规则摘要。

   - "套用品牌套件"开关，下面列出 ✓ 清单。

   如果原项目已有的节点下方面板（`canvas-config-node-panel.tsx`）已经能承载这些内容，**优先在原面板里加"计费区"和"品牌开关"**，不必新做右侧栏。设计稿里的右侧栏只是表达需要哪些信息。
6. **提示词里的 chip**：`@商品图` 这类引用 chip 用 `link` / `link.bg` 配色。品牌风格 chip 用 `#efe7d6` 底色、`#6b4e16` 文字。

- 概览左侧：
  - Logo 卡片：3 个变体。
  - 品牌色卡片：色块、名称、HEX；点击色块可以编辑（antd ColorPicker）。
  - 产品 SKU 网格。
  - 风格参考网格：勾选的图片有 2px 黑色外描边，点击切换 `attachOnGenerate`。
- 概览右侧：

### 05 用量与计费（`/billing`）· `design/png/05-用量与计费.png`

- 头部：标题，副标题是"{套餐} · 每月 N 点 · {重置日} 重置 · 失败任务自动退点"。右侧有"导出账单"（导出 CSV，来自 transactions）和"充值点数"两个按钮。
- 4 张统计卡片：剩余点数（带进度条和预计用尽日期）、本月消耗（环比）、生成次数（按类型拆分）、失败已退还（次数和成功率）。
- 每日消耗：堆叠柱状图（图片、视频），x 轴是日期。用纯 div 实现，或者用一个轻量图表库；**不要**为此引入很重的依赖。
- 成员用量表：owner 和 admin 可见。占比条 ≥ 90% 时用 `warning` 色。"上限"一列可以点击编辑，用 InputNumber，可以留空表示不限。
- 右侧：
  - 充值点数包：单选卡片加"去支付"。MVP 没有在线支付，按钮改为"联系管理员 / 使用兑换码"，点击弹出兑换码输入框。
  - 模型计价：来自 `/models` 的 price_hint。
  - "自带 API Key 模式"说明卡片：开关指向配置页。这个开关只是入口，不在这里切换。
- `billingEnabled=false`（私有化部署）时，隐藏充值相关区块，统计卡片的标题改为"用量统计"。

## 5. 通用状态

| 状态 | 处理 |
|---|---|
| 加载中 | 卡片骨架屏（antd `Skeleton`），不要整页转圈 |
| 空状态 | 一句说明加一个主操作按钮。例如模板为空时显示"还没有团队模板，在画布中框选节点即可保存" |
| 接口错误 | antd `message.error(服务端返回的 message)`，页面区块显示"加载失败，重试" |
| 402 点数不足 | `insufficient-credits-modal`：显示"本次需要 X 点，剩余 Y 点"，按钮有"去充值"和"知道了"。节点上显示错误状态，原因写"额度不足" |
| 成员超出上限 | 同一个弹窗，文案改为"已达到本月个人上限（N 点），请联系管理员调整" |
| 未登录访问受保护的页面 | 跳转 `/login?redirect=…` |

## 6. 登录与注册页（设计稿未画，按下面的说明实现）

- 居中卡片，宽 400px，底色 `bg.app`，卡片用 `bg.card`。
- 卡片内容依次是：产品名、副标题"AI 视觉创作画布"、邮箱输入、密码输入、主按钮、底部切换"没有账号？注册"。
- 注册成功后跳 `/`；如果带了邀请 token，跳到该工作区的首页。
- 邀请落地页 `/invite/:token`：显示"{邀请人} 邀请你加入 {工作区}（角色）"，已登录时显示"接受邀请"，未登录时显示"登录后接受"。
