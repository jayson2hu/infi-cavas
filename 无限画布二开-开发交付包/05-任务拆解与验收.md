# 05 · 任务拆解与验收

> 每个任务对应一个 PR，按编号顺序做。前一个里程碑的验收通过后，再开始下一个。
> 每个 PR 都要做到：
> 1. 列出改动的原有文件和改动原因；
> 2. 更新 `CHANGELOG.md` 的 Unreleased 部分（AGENTS.md 有要求）；
> 3. `bun run typecheck` 和 `bun test` 都通过；
> 4. 新增的环境变量写进 `.env.example`。
