## 怎么交给 ChatGPT

**推荐用 Codex（ChatGPT 里的编码代理）并连接 GitHub：**

1. 在 GitHub 上 fork `basketikun/infinite-canvas`，建一个 `dev` 分支。
2. 把本交付包放进仓库的 `docs/dev-pack/` 目录，提交上去。这样 Codex 能同时看到源码和文档。
3. 在 Codex 里选择这个仓库，第一条消息粘贴 `00-开发指令.md` 的全文。为了让它找到文件，开头再加一句："资料在 `docs/dev-pack/` 下"。

**如果只用普通 ChatGPT 对话：**

1. 上传本交付包的 zip，再上传 fork 后仓库的源码 zip（在 GitHub 页面上点 Code → Download ZIP）。
2. 第一条消息粘贴 `00-开发指令.md` 的全文。
3. 每次只让它做一个任务。它给出代码后，你在本地应用、运行 `bun run typecheck` 和 `bun test`，把报错原样贴回给它。

## 需要你自己决定的事项（已在文档中用占位或默认值处理）

- 产品名：`BRAND_NAME`，设计稿里写的是 `[品牌名]`。
- 点数单价、注册赠送点数、充值包价格：已给出默认值，可以在后台调整。价格在设计稿里写的是 `[¥ 价格]`。
- 上游模型供应商和具体模型名：在后台配置。文档里的 `gpt-image-2`、`sora-2` 等只是示例。
- 面向中国大陆用户上线前：生成式 AI 服务的备案和内容安全审核方案。文档里只预留了审核钩子。
