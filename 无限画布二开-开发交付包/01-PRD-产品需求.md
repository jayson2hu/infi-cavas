# 01 · 产品需求文档（PRD）

## 1. 一句话定位

一个面向团队的 AI 视觉创作画布：把电商、短视频、品牌物料等**行业工作流做成可复用模板**；生成时**自动套用品牌规范**；按**点数计费**，平台统一托管模型 Key。

产品基于开源项目 infinite-canvas（MIT）二次开发，保留其无限画布、节点编排、插件、本地 Agent 等能力。

## 2. 为什么做（相对原项目的增量）

| 原项目现状 | 用户痛点 | 本产品的解决方式 |
|---|---|---|
| 需要用户自己找 API、填 Base URL 和 Key | 非技术用户卡在第一步；团队无法统一管理 Key | 平台托管模型，登录即用，按点数扣费 |
| 空白画布，靠用户自己搭流程 | 每次从零开始，好的流程无法复用 | 行业模板：预连好的节点组 + 变量表单，一键铺开、一键运行 |
| 品牌色、风格、产品图散落各处 | 输出风格不统一，每次都要重复写提示词 | 品牌套件：Logo、色板、SKU、风格参考图、必带词和禁用词，生成时自动注入 |
| 数据只在浏览器本地 | 换电脑就丢；团队无法共享 | 账号 + 工作区；模板、品牌、用量存在云端（MVP）；画布云端化放在第 2 期 |

## 3. 目标用户

| 画像 | 典型任务 | 关注点 |
|---|---|---|
| 电商设计师 / 运营 | 商品主图、详情页、活动图、多平台尺寸 | 出图快、风格统一、尺寸齐全 |
| 短视频创作者 | 脚本 → 分镜 → 图生视频 | 分镜连贯、视频成本可控 |
| 企业设计团队 | 品牌物料延展、多人协作 | 品牌合规、权限、预算管控 |
| 开发者 / 私有化客户 | 部署到内网、接自有模型 | 自带 Key 模式、插件扩展 |

## 4. 范围

### 4.1 MVP（第 1 期）必须有

1. **账号与工作区**
   - 邮箱 + 密码注册登录。
   - 每个用户注册时自动创建一个个人工作区；可以再创建团队工作区并邀请成员。
   - 角色分 owner / admin / member 三种。
2. **平台模型网关与点数计费**
   - 平台渠道开箱即用：前端内置一个"平台"渠道，模型列表来自服务端。
   - 每次生成先冻结预估点数，成功后按实际结算，失败全额退还。
   - 余额由两部分组成：套餐月度点数（每月重置）+ 充值点数（不过期）。扣费时先扣套餐点数。
   - 管理员可以给成员设月度上限。
   - 用量与计费页面（见设计稿 05）。
   - MVP 的充值方式：管理员后台手动加点 + 兑换码。在线支付放第 2 期，但要预留接口。
3. **品牌套件**
   - 每个工作区可以有多个品牌，其中一个是默认品牌。
   - 品牌内容：Logo（多个变体）、品牌色（名称 + HEX）、产品 SKU（图片 + 名称 + 规格）、风格参考图（可勾选"随生成附带"）、必带描述词、禁用词、默认模型参数。
   - 画布顶部可以切换当前品牌；生成配置节点可以单独关闭品牌套件；管理员可以设为"强制套用"。
   - 品牌页展示"生成时实际注入的内容"预览。
4. **行业模板**
   - 模板中心：按行业分类浏览，包括官方模板和团队自建模板。
   - 模板详情：变量表单、运行步骤、每步预估点数。
   - "在新画布中使用"：新建画布并铺好节点，这一步不扣点。
   - 画布内的模板运行条：显示当前步骤，提供"运行全部"并显示预计点数。
   - "把当前画布（或选中节点）存为团队模板"。
   - 首发 6 个官方模板：电商主图套图、商品详情页长图、短视频分镜、品牌活动海报、小红书种草组图、门店物料延展。
5. **工作台首页**（设计稿 01）：模板入口、最近画布、当前品牌套件、生成任务列表、点数余额。
6. **保留原有全部功能**，包括自带 Key 模式。原有的渠道配置作为"自带 Key 模式"继续可用，这种模式下不扣平台点数（私有化场景）。

### 4.2 第 2 期

- 画布云端存储、多端同步、分享链接（只读 / 可编辑）。
- 在线支付（微信支付、支付宝）、套餐订阅、发票。
- 生成记录按品牌归档，支持素材入库审批。
- 模板市场：社区模板，可选付费。

### 4.3 明确不做（本期）

- 实时多人协同编辑（类似 Figma 的光标同步）。
- 自研模型。
- 移动端 App（Web 端做到手机宽度可用即可）。

## 5. 核心用户流程

### 流程 A：新用户第一次出图（目标：注册后 3 分钟内出第一张图）

1. 注册并登录，系统自动创建个人工作区，赠送体验点数（[体验点数，待定]）。
2. 首页点"电商主图套图"，在模板详情里上传商品图、填写卖点，点"在新画布中使用"。
3. 进入画布，节点已经铺好。点运行条上的"运行全部 · 预计 48 点"，弹出确认框，确认后开始。
4. 结果节点陆续出现，顶部点数实时减少。失败的节点显示"已退还 N 点"。

### 流程 B：团队管理员配置品牌

1. 创建团队工作区，邀请成员。
2. 品牌资产里新建品牌：上传 Logo、填色板、批量上传 SKU、上传风格参考图并勾选随生成附带，填写必带词和禁用词，然后设为默认品牌。
3. 成员在画布里生成时自动套用这个品牌。生成配置节点的面板里显示"已套用品牌套件 ✓"。

### 流程 C：沉淀团队模板

1. 设计师在画布里调好一套流程，框选节点后选择"存为团队模板"。
2. 填写名称、行业、描述，并把某些输入节点标记为"变量"（例如商品图、卖点）。
3. 模板出现在模板中心的"团队自建"分类里。

### 流程 D：额度不足

1. 发起生成时余额不足以冻结预估点数，网关返回 402。
2. 前端提示"点数不足，本次需要 N 点，剩余 M 点"，附"去充值"按钮。节点状态显示为错误，原因写"额度不足"。

## 6. 点数规则（MVP 默认值，管理员可调）

| 模型 / 规格 | 单价 |
|---|---|
| 图片 · 标准（最长边 ≤ 1536） | 4 点 / 张 |
| 图片 · 高清（最长边 > 1536） | 8 点 / 张 |
| 视频 | 12 点 / 秒 |
| 文本 | 输入 0.5 点 / 千 token，输出 2 点 / 千 token，向上取整，每次至少 1 点 |
| 语音合成 | 2 点 / 千字符 |

> 以上数字是占位默认值，请写进 `pricing_rules` 表，**不要硬编码**。点数与人民币的换算比例由运营决定，充值包价格在设计稿中保留为 `[¥ 价格]` 占位。

## 7. 成功指标

- 激活率：注册后 24 小时内完成首次成功生成的比例。
- 模板使用率：通过模板创建的画布占新建画布的比例。
- 生成成功率：成功次数 / 发起次数（按模型统计）。
- 计费准确性：冻结后未结算超过 30 分钟的记录数，应为 0。
- 付费转化：工作区首次充值的比例（第 2 期开始统计）。

## 8. 非功能需求

- **安全**：平台 Key 只存在服务端并加密保存；密码用 argon2id 哈希；会话放在 httpOnly Cookie 里；接口有限流。
- **合规**：服务面向中国大陆用户时，需要考虑生成式 AI 服务的备案、内容安全审核、生成内容标识等要求。网关预留"内容审核"钩子（提示词和结果各一个），MVP 先实现禁用词拦截。
- **性能**：网关额外增加的延迟不超过 100ms（不含上游耗时）；支持图片请求 10 分钟超时（与原前端的 `IMAGE_REQUEST_TIMEOUT_MS` 一致）。
- **可私有化**：用一个 `docker compose up` 启动 web、server、postgres、minio 全套服务；可以关闭计费（`BILLING_ENABLED=false`）。
- **开源署名**：保留"基于 infinite-canvas"的标识，并在关于页附上原项目链接和 MIT LICENSE。
