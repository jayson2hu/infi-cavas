## 账本约定

`hold(input)` 保存 `generation_jobs`，返回 `{ job, balance, balanceBreakdown }`。输入包含工作区、用户、模型、能力、接口、预估点数及可选生成上下文；可传 `jobId`。

`settle(jobId, actual, { usage?, providerId? })` 与 `refund(jobId, { status?, error?, providerId? })` 返回相同结构。退款状态可为 `failed` 或 `timeout`。重复调用或结算与退款竞争时保留第一个终态，不重复追加流水。

锁顺序统一为工作区 → 成员/任务 → 点数桶。工作区行锁也覆盖没有可用桶的情况；冻结时在锁内重新读取成员身份和上限。套餐桶优先，其余按有效期和创建顺序扣除。余额不足和成员超限整体回滚，不留下任务或冻结流水。

实际消耗小于冻结额时逆序退回原桶；超过冻结额时补扣可用余额，余额不足则标记 `overdraft`，`chargedCredits` 只记录实际扣到的点数。恢复到过期桶的点数紧接着产生 `expire` 流水，不能重新使用。管理员提前切换套餐或手工提前周期结束时，也结束旧套餐桶的有效期，避免未完成任务稍后退款复活旧额度。

关闭计费时仍保存任务和实际 usage，不检查余额及成员上限，不追加虚假的扣款流水。任务参数中的服务端 `billingEnabled` 标记保留发起时的计费模式，后续配置切换不会对免费任务补扣。

## 扫描器

- `sweepHeldJobs(pollVideo?)`：每 5 分钟调用。扫描超过 30 分钟的冻结任务，视频通过传入的 `pollVideo(videoTaskId)` 回查上游；超过 2 小时的任务也先确认终态，仍未完成才超时退款。缺少视频任务记录及非视频孤儿任务在 30 分钟后退款。
- `sweepPeriods()`：每小时调用。过期桶记录过期流水；已结束套餐只发放当前有效周期的点数，不追发停机期间已过期的月份。月份计算使用 PostgreSQL `interval '1 month'`。
- `startSweeper(pollVideo?)` 启动两类扫描并返回停止函数，不启动 HTTP 监听。
- 两类扫描分别使用事务级 advisory lock，避免多个服务实例同时扫描。单个任务失败记入返回值的 `errors`，不影响其余任务；错误日志不包含上游内容或密钥。

## HTTP 数据约定

- `/billing/summary` 补齐余额分桶、月度消耗、上月同期消耗、按能力的任务数、失败退款、个人消耗/上限、预计用尽日和计费开关；`successRate` 是 0–100 的百分数。
- `/billing/daily` 返回指定日期范围内有任务的日期，按图片、视频、文本和音频汇总；空日期由展示层补齐。
- 成员只能在 `/billing/jobs` 查看自己的任务；`/billing/members` 与 `/billing/transactions` 仅 owner/admin 可访问；兑换仅 owner 可执行。
- jobs、transactions 和管理员工作区列表每页 50 项，`nextCursor` 为不透明游标。游标保留 PostgreSQL 微秒精度，并用 ID 作为同时间排序键，防止 JavaScript Date 截断精度导致漏项。
- 管理员加点和套餐修改在事务内再次校验平台管理员身份；兑换码使用工作区锁与兑换码锁，确保同一工作区只能兑换一次且全局使用次数不超限。
- 充值包只读取数据库实际配置；没有在线支付行为。兑换码返回列表可供管理页面导出 CSV。

本次实际使用 Bun 1.3.14 和本机 PostgreSQL 16 测试库运行，没有启动 HTTP 服务。HTTP 测试通过 `app.request` 调用真实路由。

| --- | --- |

| M2.2：事务回滚、桶顺序、成员上限、差额结算 | 全部通过；管理员不受 member 上限限制；补扣不足不出现负余额 |

## 问题与验收边界

- 发现并修复：毫秒游标会遗漏同毫秒内的 PostgreSQL 微秒记录；现使用原始微秒时间。
- 发现并修复：提前结束套餐后，旧冻结任务退款可能复活旧额度；现同时结束旧桶有效期并记录过期流水。
- 发现并修复：直接退款超过 2 小时的视频可能把实际已完成任务当失败；现先回查上游终态。
- 全套测试日志出现 `archive_failed` / `video_archive_failed`，该轮未配置可成功归档的 S3 测试依赖。因此该轮通过仅覆盖已断言的网关和账本行为，不能宣称已验收 S3 归档。
- 本文不宣称真实供应商出图、浏览器计费页面或 Docker Compose 验收已完成。
