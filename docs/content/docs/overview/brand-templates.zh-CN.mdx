# 品牌与模板

品牌与团队模板保存在当前工作区的后端。画布项目、画布素材及自带 Key 配置仍主要保存在浏览器本地；登录账号不会把画布自动同步到云端。

## 配置品牌

在“品牌资产”创建品牌，维护 Logo、商品 SKU、风格参考图、色板、必带词、禁用词及默认生成参数。图片支持 PNG、JPEG、WebP，单张不超过 20MB；上传后服务端核对实际图片内容并固化素材。预览在修改后约 300ms 更新，可核对实际注入的规则。

owner/admin 管理默认品牌、强制套用和编辑者。被指定的品牌编辑者可以修改该品牌内容，不能修改强制配置，也不能删除默认或强制品牌。普通成员可以读取素材与使用品牌。

在画布顶栏选择品牌，节点可以单独关闭品牌规则。管理员强制套用时，节点开关禁用；即使请求关闭品牌，后端仍应用强制规则。平台请求会注入文字并按模型参考图上限追加勾选的品牌素材，必要时将文生图转换为参考图编辑。用户参考图保留优先顺序；Logo 和风格图是否附带由品牌设置决定。

自带 Key 渠道只注入品牌文字，不自动发送平台品牌参考图，也不扣平台点数。品牌默认参数只作为默认值，节点显式设置优先。禁用词是生成提示约束，不能保证模型输出绝不包含该词。

将 SKU 从品牌侧栏拖入画布后，它成为普通本地图片节点，原图进入浏览器存储；画布 ZIP 导出包含该原图。

## 使用行业模板

1. 在模板中心选择官方或团队模板，查看步骤与估价。
2. 填写文本、选项和图片变量；图片可上传，也可选当前品牌 SKU。
3. 点击“在新画布中使用”，或从现有画布的模板侧栏插入。插入创建新节点与连线，可撤销，不扣点，使用次数增加一次。
4. 确认模型与预计点数后运行。步骤按顺序执行，同一步的节点并发；后续节点读取前一步实际生成的结果。
5. 失败后停在当前步骤。“继续运行”保留已完成节点；停止取消当前请求并阻止下游。全部完成后再次运行会重新执行整套流程，产生新费用。

视频刷新后恢复已有任务查询；等待自动恢复或立即继续均复用原任务。普通已移除的自带 Key 渠道不会自动回退到平台收费渠道，需要重新配置。

六套官方流程包括：电商主图套图、商品详情页长图、短视频分镜、品牌活动海报、小红书种草组图和门店物料延展。电商主图先生成同节点 5 张候选，再把当前主图适配为 3 张尺寸图，共 8 张。初始化价格下共 40 点。其他模板保留文本、图片、视频或语音的完整步骤，需要运营者配置相应的可用模型路由。

## 保存团队模板

在画布选择节点或分组后使用“保存为团队模板”；未选择时使用整张画布。设置名称、类别、说明和可选封面，把输入文本或图片标为变量。嵌套分组及内部连线会保留，输入图片上传至工作区存储；历史生成结果与本地运行状态不会作为模板输出保存。

生成配置与历史结果归并成可重复执行的空目标，保存有效模型参数并自动构造依赖步骤。外部节点引用、循环依赖或无法还原的图会报错，请先补全选择范围或修正连线。保存成功后可在“团队模板”找到，并以全新节点 ID 再次实例化。

owner/admin 和当前工作区的品牌编辑者可以发布、编辑或删除团队模板；官方模板仅平台管理员可修改。模板图片仅向具备相应工作区或官方模板访问权的用户开放。

## 已验证范围

六套流程已通过真实浏览器界面、PostgreSQL 与 S3 协议存储的受控上游验收，包含保存再使用、失败退款、停止与视频刷新恢复。真实供应商还完成了图片生成、品牌参考图编辑和完整电商模板验证：注册至8图完成84.84秒，验收工作区余额200→160，8个归档与上游图片哈希一致。其文本模型请求被拒绝，视频和语音能力尚未验证。供应商输出像素仍与请求有差异；受控验收或真实图片验收都不等于生产 Docker 部署验收。
