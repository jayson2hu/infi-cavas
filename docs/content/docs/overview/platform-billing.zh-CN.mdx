# 计费说明

平台渠道使用当前工作区的点数；自带 Key 渠道由浏览器直接调用供应商，不扣平台点数。插入、查看、保存模板不收费，点击生成后才创建任务。供应商自己的费用由对应供应商计收。

## 一次生成如何记账

1. 提交前检查工作区权限、余额与普通成员的月度上限。不满足时返回 402，不创建任务，也不调用供应商。
2. 按当次模型价格冻结预估点数，余额立即减少。任务保留模型、请求参数和账本关联。
3. 成功后按实际用量结算，少于冻结量的部分退回；需要补扣时只扣可用余额，不产生负余额，未覆盖差额记录在任务中。
4. 失败或取消时，尚未结算的冻结点数退回原点数桶。重复结算、退款不重复记账；原桶已到期时会同时记录过期流水，不把已过期额度重新变成可用余额。

图片批次在画布中按单图请求生成，个别图片失败只退还对应请求；已经成功的图片正常结算。模板停止会取消当前请求，后续步骤不再启动。已成功结算的任务不会因稍后收到取消而再次退款。视频任务可能已由供应商接收，浏览器停止轮询不等于供应商取消任务；服务端仍会确认终态并结算或退款。

## 价格规则

以下是首次初始化的可编辑价格，运营后台当前配置才是实际依据。

| 能力 | 初始规则 | 结算依据 |
| --- | --- | --- |
| 图片 | 最长边不超过 1536 像素或 auto：4 点；超过：8 点 | 请求尺寸档位与实际返回图片数 |
| 视频 | 12 点/秒 | 请求的视频秒数 |
| 文本 | 输入 0.5 点/千 token，输出 2 点/千 token；先冻结 10 点，最低 1 点 | SSE 最终 usage；上游未给有效 usage 时使用冻结估价 |
| 语音 | 2 点/千字符 | 实际输入的 Unicode 字符数 |

每个请求的最终点数向上取整。品牌文字与参考图不会额外增加图片张数收费；语音品牌规则通过 instructions 传入，不加入朗读内容。模板的静态卡片估价来自保存时的步骤，详情和运行确认按当前模型配置重新估计，最终以任务明细为准。

实际图片像素由供应商决定。平台按请求的尺寸档位计价并保留原始输出，不擅自拉伸图片。真实模板验收中，1024×1024 请求返回1374×1145或1254×1254，1088×1920返回941×1672，1248×1664返回1086×1448；不能据请求参数承诺精确输出尺寸。

## 点数来源与成员权限

注册赠送量由 `SIGNUP_BONUS_CREDITS` 配置。平台管理员可以手工加点、生成兑换码及设置月度套餐；当前版本没有在线支付。兑换码受总使用次数、到期时间限制，同一工作区不能重复兑换同一码。

扣点优先使用订阅桶，再按有效期和创建顺序使用其他桶。月度套餐到期后，原订阅额度过期，新周期发放新桶；维护任务每小时检查周期。生成任务与素材清理每 5 分钟检查，长时间冻结任务按既定超时规则回收。不要通过手工修改余额列代替账本操作。

普通 member 的已结算与冻结用量共同参与月度限额检查；owner/admin 不受该个人上限限制，但仍受工作区余额约束。成员只能查看自己的生成任务，工作区成员用量和完整流水仅向 owner/admin 开放。平台管理员是独立身份，不自动获得其他工作区的成员权限。

## 用量统计与排障

`BILLING_ENABLED=false` 时保留生成任务与用量记录，生成不扣平台点数，计费页显示“用量统计”。任务记录提交时的计费模式，运行期间修改环境配置不会改变已有任务的计费承诺。

余额不足时先检查当前工作区，再查看余额、未完成任务和个人上限。供应商错误时通过任务明细核对失败原因及退款流水。流式文本在结束后刷新余额；视频刷新页面会恢复已有任务查询，不应重复创建同一任务。
